# Project Title: YUNA - Yielding Universal Navigational Academics

# Description:
# An open- source, web-based, interactive review application designed for local public school teachers and their students that transforms lesson reviews into a Family Feud-style game. The application allows educators to input custom curriculum questions and project the game onto a single screen for the entire class to enjoy. Its primary purpose is to increase classroom engagement and active participation without requiring individual student devices.
